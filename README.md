Midnight Vault — a complete top-down heist game: crack 5 vaults (museum, bank, casino, gallery, penthouse) past 21 patrolling guards and 14 sweeping cameras. Vision cones that react, a gradual alarm meter with lockdown at 100%, smoke bombs and EMP tools at a cost, vent hiding while sneaking, lockpicking, loot, timer, lives, 3-star heists, minimap and synthesized sound. No build step, no network — plain static files under game/.

## Run it

Serve `game/` with any static server and open `game/index.html` in a desktop browser, for example:

```sh
python3 -m http.server --directory game 8080
```

Then open http://127.0.0.1:8080/ — WASD / arrows to move, Shift to sneak, Q smoke bomb, R EMP, hold E by the vault to crack it, click the floor to walk there, P to pause, M to mute.
